# LLMOps 启动指南

## 前置准备

1. 安装 Docker Desktop
2. 安装 Ollama（本地嵌入模型，默认地址 http://127.0.0.1:11434）

## 启动步骤

### 1. 配置环境变量

```bash
cd docker
cp .env.example .env
# 编辑 .env 文件，填入真实密钥
```

### 2. 启动所有服务

```bash
cd docker
docker compose --env-file .env up -d
```

启动的服务包括：
- PostgreSQL（数据库）
- Redis（缓存）
- Weaviate（向量数据库）
- llmops-api（Flask 后端）
- llmops-celery（异步任务队列）
- llmops-ui（Vue 前端）
- Nginx（反向代理）

### 3. 查看服务状态

```bash
docker compose ps
```

### 4. 查看日志

```bash
docker compose logs -f        # 所有服务
docker compose logs -f api    # 单个服务
```

### 5. 停止服务

```bash
docker compose down
```

## 开发模式（不用 Docker）

### 后端

```bash
cd llmops-api
uv sync
uv run python app/http/app.py
```

### Celery Worker

```bash
cd llmops-api
.\start_celery.ps1
```

### 前端

```bash
cd llmops-ui
npm install
npm run dev
```

## 数据库迁移

```bash
cd llmops-api
flask --app app.http.app db migrate -m "描述"
flask --app app.http.app db upgrade
```
